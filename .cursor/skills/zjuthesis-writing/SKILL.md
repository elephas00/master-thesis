# zjuthesis 学位论文文风

面向浙大研究生学位论文正文与摘要。目标是平稳、可核验的学术叙述，避免聊天/博客式强调。

## 硬约束（优先遵守）

### 1. 少加粗、不加情绪强调

- **正文叙述不要用加粗做语气强调**（包括 Markdown `**…**`、LaTeX `\textbf{…}` 用于“务必注意/关键是”一类）。
- 允许的加粗仅限版式惯例，例如结果表中同列最优/次优标记、已有模板要求的标题样式；不要顺手把结论句、数字、方法名加粗。
- 需要突出时：改用完整陈述句，或“其中…更为关键”“由此可见…”等平实衔接，而不是加粗单词。

### 2. 少用括号夹注

- **避免用括号塞旁白、解释、对比数字或机制说明**（中文 `（…）` 与英文 `(...)` 均控制）。
- 括号里若是完整意思，改为逗号分句、破折号很少用、或单独一句。
- 允许保留：公式编号、文献引用、缩写首次出现的规范写法（如“假阳性率（False Positive Rate，FPR）”——且同一术语全文首次后不再反复括注英文）、以及必要的数学/符号界定。
- 对比数字优先写成“验证集上分别为 a、b 与 c，测试集上分别为…”式列举，而不是“RF（0.87）…LGB（0.04）…”一串括号。

### 3. 禁止写得过满

学位论文实验解读宜克制，忌把排查笔记、答辩口径、机制猜想一次塞进同一段。

- **一段一事**：选参段只服务选参，消融段只服务消融；不要在网格分析里展开完整故障诊断，再在消融、集成节把同一故事重讲两遍。跨节只需“见上节 / 情形相近”一带而过。
- **先事实、后解释，解释宜短**：先报可核对数字与对比，再给一两句判断；机制推测最多半句到一句，用“可能 / 与…相符 / 尚需进一步验证”，禁止写成已证实的因果长链。
- **忌排查口吻与事后合理化**：少用“为判断…还是…进一步核对”“该选择同时避开了…”等修改说明腔；选参动机写验证集指标最优即可，副作用单独一句即可。
- **忌代码/超参堆砌入正文**：如 `\mathtt{is\_unbalance}`、路径名、实现细节；必要参数用自然语言概括。
- **忌辩解式重复**：同一局限或失效解释全文出现一次足够；后续节引用，不扩写。

过满的典型信号：单段超过约 8–10 行仍在叠加因果；同一 LightGBM/集成失效理由在三节各讲一遍；把“可能原因”写成“因此应归因于…并退化为…从而…”。

### 4. 与对话回复区分

- 对用户的简短说明可以用列表；**写入 `content.tex` / 摘要时改成连贯段落**。
- 不要把对话里的加粗结论、括号补充、过满排查分析原样粘进学位论文。

## 改写自检

落笔或改完一段后快速检查：

1. 是否出现叙述性 `\textbf` / `**`？有则去掉。
2. 一句话里是否超过一处解释性括号？有则拆句。
3. 关键数字与对比是否已融入句子，而不是括在词后？
4. 本段是否过满：机制是否写实过度、是否与前后节重复、是否混入排查/代码口吻？过则删到“数字 + 一句判断”。

## 反例与正例

```text
反例：因此该低谷应归因于 **LightGBM** 不稳定（而非突变特征失效）。
正例：因此该低谷应归因于 LightGBM 不稳定，而非突变特征失效。

反例：RF/XGB 仍高（约 0.87），LGB 接近 0（集成随之坍塌）。
正例：RF 与 XGB 的盘级 F0.5 仍约 0.87，LightGBM 接近 0，集成随之坍塌。

反例：为判断低谷来自特征无信息还是基学习器不稳定，进一步核对……应归因于叶式增长与 is_unbalance=False……对高梯度难例过敏并退化为全负……集成若不能抑制失效基学习器也会被拖垮……该选择同时避开了退化区。
正例：同格三轮平均显示，验证集上 RF、XGB、LightGBM 与集成分比为 0.878、0.871、0.041 与 0.081，测试集形态一致。可见突变通道仍可被 RF/XGB 利用，低谷主要由 LightGBM 失效并牵连集成所致；这可能与类别极不平衡下 boosting 对难例过敏感有关。
```

## 范围

- 适用：`body/graduate/**/*.tex`、`page/graduate/abstract.tex`、学位论文修改意见/说明类 `docs/*.md` 中拟写入正文的表述。
- 不适用：聊天回复排版；代码注释；图表脚本里的图注若模板已有固定加粗可保留。
